# Форма 12

Статическое PWA-приложение для 12-недельных тренировок. Никакого сервера, npm, сборщика и аккаунта не нужно.

## Быстрая публикация на GitHub Pages

1. Создай **публичный** репозиторий, например `forma12`.
2. Загрузи **содержимое** этой папки в корень репозитория (`index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icons/`, `fonts/`). Не загружай внешнюю папку `forma12` целиком как дополнительный уровень.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** укажи **Deploy from a branch**, ветка **main**, папка **/(root)**, затем **Save**.
5. Когда GitHub опубликует сайт, открой `https://ТВОЙ-ЛОГИН.github.io/forma12/` на iPhone в Safari.
6. Нажми **Поделиться → На экран «Домой» → Добавить**. Запускай приложение по иконке.

## Первое использование

- По умолчанию первый день курса — ближайший понедельник. Его можно изменить в **Настройки → Начало текущего курса** (принимаются только понедельники).
- Вкладка **Сегодня** позволяет отмечать прогулки и тренировки за любые даты.
- Вкладка **Курс** показывает 12 недель, нагрузки и индивидуальные корректировки.
- По воскресеньям во вкладке **Итоги** заполни обзор. В зависимости от решения приложение осторожно скорректирует нагрузку **следующей недели**.
- Во вкладке **Настройки** можно сохранить резервную копию в JSON и восстановить её, экспортировать 12-недельное расписание в `.ics`.
- После завершения курса создавай новый: предыдущий сохранится в архиве; число отжиманий задаёт стартовую интенсивность нового курса.

## Напоминания на iPhone — честные ограничения

Самостоятельное GitHub Pages PWA **не может гарантированно отправлять уведомления по расписанию при закрытом приложении**. Для настоящих Web Push при закрытом приложении нужен сервер/сервис отправки, подписка и VAPID. Это не проблема конкретной реализации.

Надёжный вариант без сервера: **Настройки → Скачать расписание .ics**. Файл содержит все запланированные занятия и воскресные обзоры на 12 недель с событиями и сигналом **за 10 минут**. Импортируй события в Календарь iPhone (способ импорта `.ics` зависит от версии iOS и настроек: может потребоваться отправить файл себе по почте или импортировать через календарный клиент). Убедись, что у календаря разрешены уведомления. Если меняешь расписание после импорта, сформируй новый файл, **предварительно удалив старые события**, чтобы не получить дубликаты.

Встроенный таймер может сигналить, пока приложение открыто и активно. Когда iPhone блокируется, JavaScript может быть приостановлен, и звук/уведомление не гарантируются. Для отдыха между подходами с заблокированным экраном используй системный таймер iPhone.

## Хранение и приватность

Данные сохраняются в `localStorage` конкретного установленного PWA. Они не передаются в облако, не синхронизируются между устройствами и могут исчезнуть при очистке сайта/удалении приложения. Используй экспорт/импорт JSON. Архив внутри приложения сохраняется локально и также входит в резервную копию.

## План нагрузки

- Силовые: понедельник, среда, пятница. Первые 2 недели по 2 подхода, затем преимущественно 3 подхода; 8-я неделя облегчённая. В программу входят отжимания, приседания, тяга рюкзака, ягодичный мостик, планка.
- Кардио: вторник, суббота. Интервалы бег/ходьба, нарастающие с постепенным облегчением на 8-й неделе.
- Ходьба: каждый день, ориентир 30–40 минут, в восстановительные дни можно меньше.
- Пересмотр: каждое воскресенье. Повышать нагрузку только при хорошей технике, без боли и с нормальным восстановлением. Не обязательно достигать предписанного объёма любой ценой.

Приложение не заменяет медицинскую консультацию. При необычной одышке, головокружении, боли в груди или суставах прекращай тренировку.

## Разработка

Полностью автономные HTML/CSS/JS. Чтобы запустить локально:

```bash
python3 -m http.server 8000
```

Открой `http://localhost:8000` в браузере. Для service worker нужен localhost или HTTPS. Изменяя `sw.js`, обновляй значение `CACHE`, чтобы сбросить старую версию офлайн-кеша.
